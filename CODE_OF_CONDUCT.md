# Código de conducta

Este proyecto busca una colaboración técnica respetuosa, clara y útil. No se toleran acoso, discriminación, amenazas, publicación de datos privados ni sabotaje deliberado.

Los mantenedores pueden retirar comentarios, rechazar contribuciones o limitar la participación cuando sea necesario para proteger a la comunidad. Los reportes deben hacerse de forma privada al mantenedor del repositorio.
