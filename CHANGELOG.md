# Changelog

All notable changes to CacaTools Media Player are documented here.

## [0.1.1] - 2026-08-16

### Added

- Local playback of video and audio files on Windows.
- Single-window playlists for multiple local media files.
- Drag and drop, Windows `Abrir con`, subtitles, playback speed and fullscreen.
- Aspect-ratio-aware playback and native window sizing for loaded media.
- Tauri 2 and Rust source with MIT licensing and public contribution guidance.
